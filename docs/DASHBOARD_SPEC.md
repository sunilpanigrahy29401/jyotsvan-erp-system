# Jyotsvan Enterprise Platform — Dashboard Specification

## 1. Overview

Jyotsvan will feature specialized dashboards tailored to managerial and operational personas. In **Phase 1**, all dashboards and analytical metric panels are strictly deferred. **No fake charts, artificial statistics, or mock KPIs are permitted.**

---

## 2. Planned Dashboards & Target Phases

### 2.1. Command Center / Hero Dashboard
*Planned for Phase 2 / Phase 3*
- Enterprise executive overview uniting real-time revenue, production throughput, inventory alerts, pending dispatches, and cash balance.

### 2.2. Manufacturing & Production Dashboard
*Planned for Phase 6*
- OEE (Overall Equipment Effectiveness), batch status tracker, rejection rates, machine downtime logs.

### 2.3. Warehouse & Inventory Dashboard
*Planned for Phase 4*
- Stock turnover, aging stock breakdown, reorder alerts, warehouse capacity utilization.

### 2.4. Sales & Distribution Dashboard
*Planned for Phase 7 & 8*
- Order fulfillment rate, field sales beat completion, distributor aging balances, territory performance.

### 2.5. Marketing Intelligence Dashboard
*Planned for Phase 10*
- Real-time blended ROAS, channel-wise CAC, campaign attribution, creative performance matrices.
